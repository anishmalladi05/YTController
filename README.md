# YTController
This is an ESP32-S3 powered BLE YouTube controller. It uses circuitpython and is hand soldered.

## Flash:
Upload the CircuitPython uf2 file (find online) and use the instructions included on the website to put it on the esp32s3
<br></br>
Delete the lib folder and put the lib folder included in my repo instead. Do the same with code.py
<br></br>
<br></br>
Flashing Done!

## Wiring:
Connect one terminal of each key to GND and the other to a pin. Change it to the correct pin in the code. It is just changing one number.
<br></br>
Connect the buck converter to the 3.3v and GND and connect the battery to the buck converter.
